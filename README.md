# app-landing

digital-raptors.com で公開している、各アプリのホームページ・プライバシーポリシーをまとめたリポジトリです。

- `index.html` — アプリ一覧（トップページ）
- `cardvalia.html` / `cardvalia-privacy.html` — Cardvalia（名刺管理アプリ）
- `lexiconrogue.html` / `lexiconrogue-privacy.html` — LexiconRogue（英単語ローグライク・デッキビルダー）

新しいアプリを追加する場合は、同じ命名パターン（`<app>.html` / `<app>-privacy.html`）で新しいページを追加し、`index.html` のアプリ一覧にカードを1つ追加してください。
